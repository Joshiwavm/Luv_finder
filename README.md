# Luv_finder

Blind spectral-line finding in the UV plane for interferometric (ALMA) data: a matched
filter on the visibilities, a jackknife as the noise reference, and a catalogue of
fitted lines.

```bash
git clone https://github.com/Joshiwavm/Luv_finder && cd Luv_finder
pip install -e ".[casa]"
```

Documentation: https://joshiwavm.github.io/Luv_finder/
