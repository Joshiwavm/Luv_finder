Luv_finder
==========

Blind spectral-line finding in the UV plane for interferometric data.

A parametric line model is evaluated directly on the visibilities and
cross-correlated with the data over a grid of positions, sizes, widths and
fluxes. A jackknifed copy of the data provides a signal-free noise realisation
on the same grid.
